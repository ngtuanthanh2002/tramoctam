# Trà Mâm Xôi Sâm Tố Nữ

Landing page Next.js (App Router) — chuẩn SEO, sẵn sàng deploy Vercel.

## Dev

```bash
npm install
npm run dev
```

## Deploy Vercel

1. Push repo lên GitHub
2. Import project trên [vercel.com](https://vercel.com)
3. (Tuỳ chọn) set env `NEXT_PUBLIC_SITE_URL` = domain thật của bạn

Framework Preset: **Next.js** — không cần config thêm.
